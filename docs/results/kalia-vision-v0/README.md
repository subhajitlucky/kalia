# KALIA-Vision v0 — text-to-image on synthetic shapes

Status: **data ready; 500-step diffusion smoke running.** Full 20k-step model
trains in the 30-hour window.

## Data

- 32×32 RGB synthetic images, one shape per image.
- Shape: circle / square / triangle.
- Color: red / green / blue / yellow.
- Position: left / center / right.
- Captions: two templates.
- 50,000 train / 5,000 val / 5,000 test; fully generated by `synthetic_vision.py`.
- No external images, no pretrained vision weights.

## Model

- Frozen KALIA v0.3.1 text encoder; mean-pooled 512-d caption embedding.
- Conditional DDPM U-Net trained from scratch on 32×32 images.
- DDIM sampling (100 steps).
- Training: 20,000 steps, batch 128, AdamW 2e-4; 30-hour window.

## Bars

- **W-1** requested shape ≥ 0.80.
- **W-2** requested color ≥ 0.80.
- **W-3** requested position ≥ 0.70.
- **W-4** no pretrained vision weights; KALIA frozen.
- **W-5** held-out sample grid saved.

Attribute accuracy is measured by a small classifier trained from scratch on
the real synthetic images as a diagnostic.
