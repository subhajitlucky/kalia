# KALIA-Audio v0 — synthetic spoken commands

Status: **clean pass of A-1…A-3.** A 136k-parameter 1D CNN recognizes six
synthetic spoken commands from raw 16 kHz waveforms. From scratch; no
pretrained audio weights.

## Result

- Held-out test accuracy: **0.912** (1,000 clips).
- Validation accuracy: **0.916**.
- 136,326 parameters; 15 epochs in **0.38 minutes**.
- Checkpoint sha `a6ea7051…`, 545KB.
- Per-class coverage: all six commands present; class 5 is the weakest at
  0.766, the others are at or near 1.0.

## Data

Fully synthetic formant audio, generated by `synthetic_audio.py`:

- Commands: left, right, up, down, stop, go.
- 16 kHz, 0.6 s.
- Unique vowel/formant sequence per command, plus a consonant burst.
- 5,000 train / 1,000 val / 1,000 test.
- No external audio.

## Caveat

This is a **toy vocabulary on synthetic formant tones**, not real speech. It is
the first owned “ear”, not a speech recognizer. The next step is real speech
commands (external audio data, still no pretrained model), then KALIA response
generation and TTS.
