# Pre-registration — X57: KALIA-Imagine

Registered: 2026-11-08, before the gallery run.

## Goal

A **fun, from-scratch visual imagination toy** that shows what the 58M stack can
do that a text chat model cannot:

1. **Morph** — interpolate the text conditioning between two scenes and draw
   the frames, with the captioner reading each frame back.
2. **Dream** — start from a scene, repeatedly edit its caption, draw the edit,
   and read it back; a visual chain.
3. **Edit** — take a real synthetic scene, caption it, apply a word edit, draw
   the edited scene, and read it back.

This is a capability/demo pack, not a chat model and not a benchmark claim.

## From-scratch provenance

- text trunk: KALIA v0.3.1, ours;
- diffusion: v1 U-Net, ours;
- captioner: v2.1 CNN encoder + LoRA, ours;
- scenes: `synthetic_vision_v1.py`, ours;
- caption editor: deterministic rule-based code written here (not a learned
  model, not a distilled teacher);
- no external vision weights, no external model inference, no distillation.

## Method

- No training. Frozen v0.3.1, v1 diffusion and v2.1 captioner.
- Morph: linear interpolation of the 512-d bidirectional caption embeddings;
  100-step DDIM sampling; batched greedy captioning.
- Dream: 10 steps; each step applies a random rule-based edit to the current
  caption (swap sides/colors/shapes, change a color/shape, make both the same,
  invert colors), draws it and captions the result.
- Edit: 6 real synthetic scenes × 4 edits = 24 edits; the target is the edited
  source caption; the readback is the caption of the drawn edited scene.

## Bars

| ID | prediction | threshold |
|---|---|---|
| **I-1** | morph endpoint exact over 12 endpoints (6 pairs) | ≥ 0.80 |
| **I-2** | edit survival over 24 edits | ≥ 0.70 |
| **I-3** | dream edit survival over 10 steps | ≥ 0.70 |
| **I-4** | gallery artifacts: `morph.gif`, `dream.gif`, `edit_grid.png`, metrics | pass |
| **I-5** | from scratch; no external weights/distillation | pass |

## Decision rule

- **I-1…I-3 pass:** release **v0.8.0-imagine** capability/demo pack.
- **Any fail:** log the boundary; no tuning after the result.
- The gallery is the deliverable; the bars only keep the demo honest.

## Cost

CPU inference only; ≤ 1 GPU-h equivalent.
