# Pre-registration — KALIA-Audio v0: synthetic spoken commands

Registered: 2026-11-06, before the audio GPU run.

## Goal

Give KALIA a first **audio input** module, fully from scratch: a small 1D CNN
recognizes six synthetic spoken commands. This is a toy vocabulary, not real
speech; it is the first owned “ear”, to be followed by a real speech dataset.

## Data

Fully synthetic, generated by our own formant synthesizer:

- Commands: left, right, up, down, stop, go.
- 16 kHz, 0.6 s waveforms.
- Each command has a unique vowel/formant sequence and consonant burst.
- 5,000 train / 1,000 val / 1,000 test.
- No external audio; no pretrained audio weights.

## Model

- 1D CNN on raw waveform (conv blocks 32/64/128/256, global pool, 6-way head).
- Trained from scratch, ~15 epochs, AdamW.
- The KALIA language core is not trained; the audio encoder is the module.

## Decision rule

- **A-1…A-3 pass:** release **v0.6.0-audio-commands** capability pack.
- **Any fail:** log the boundary; no release.
- Next window: real speech commands (external audio data, still no pretrained
  model), then TTS.

## Cost

Data CPU. Training ≤ 1 GPU-h; fits the current window.
