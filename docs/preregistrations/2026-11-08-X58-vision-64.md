# Pre-registration — X58: 64×64 three-object vision

Registered: 2026-11-08, before the 64×64 GPU runs.

## Goal

Scale the visual imagination toy from 32×32 two-object scenes to **64×64
three-object scenes**: four shapes, six colors, left/center/right. Retrain the
diffusion and captioner from scratch on the new grid, keep KALIA v0.3.1 frozen,
and rerun the morph/dream/edit gallery.

This is a capability scale-up, not a chat model and not a standard-benchmark
claim. It tests whether the compositional see→draw→see loop survives higher
resolution and a third object.

## Data

- 64×64 RGB, three objects at left/center/right.
- Shapes: circle, square, triangle, star.
- Colors: red, green, blue, yellow, purple, orange.
- Caption: “a {c1} {s1} on the left, a {c2} {s2} in the center, and a {c3} {s3}
  on the right.”
- 13,824 combinations. **20% held out** (2,765) for the captioner’s
  compositional split; the diffusion is trained on all combinations.
- 50k train / 5k val / 5k test. No external images.

## Models

- **Diffusion:** v1 U-Net architecture, trained from scratch at 64×64, 25k
  steps, batch 128.
- **Captioner:** from-scratch CNN encoder + 4 image tokens + rank-16 LoRA on
  frozen v0.3.1, 8 epochs, batch 64.
- **Text conditioning:** the corrected bidirectional masked-mean embedding.
- **Classifier:** from-scratch 6-head CNN at 64×64 for generated-image quality.

All weights and data are ours; no pretrained vision, no distillation.

## Bars

| ID | prediction | threshold |
|---|---|---|
| **V64-1** | captioner held-out exact (unseen combos) | ≥ 0.90 |
| **V64-2** | captioner seen exact | ≥ 0.95 |
| **V64-3** | diffusion classifier exact, generated held-out | ≥ 0.80 |
| **V64-4** | see→draw→see loop held-out exact | ≥ 0.80 |
| **V64-5** | imagine edit survival at 64×64 | ≥ 0.70 |
| **V64-6** | from scratch; artifacts | pass |

## Decision rule

- **V64-1…V64-5 pass:** release **v0.9.0-vision-64** with the 64×64 checkpoints
  and a new morph/dream/edit gallery.
- **Any fail:** log the boundary; no tuning after the result. The failure
  pattern is evidence on resolution/object-count scaling.
- Public base remains v0.3.1; no Hugging Face base release.

## Cost

≤ 5 GPU-h.
