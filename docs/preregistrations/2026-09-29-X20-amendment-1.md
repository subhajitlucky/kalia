# Amendment 1 to X20 — correct the static arm's parameter count

Registered: 2026-09-29, **before the arm has been trained and before any GPU time
was spent on it**. The original X20 registration is hash-anchored at
`d5ec8deef729147fed5fb260b1a5007031b2d7c3429b1b45c945bffba9cef6f4`
(`docs/preregistrations/2026-09-29-X20-static-gate.md`).

## What is being corrected

The arm table gave the static arm as **29,996,736** parameters and described it as
"strictly smaller than the gated arm by 76,032 parameters". **Both numbers are
wrong.** The measured count is **29,999,040**, which is 73,728 fewer than the gated
arm.

The arithmetic that was missed, per block:

| piece | gated arm | static arm |
|---|---|---|
| `w1` weight + bias | 384×32 + 32 = 12,320 | replaced by a learned constant of 32 |
| `w2` weight + bias | 32×384 + 384 = 12,672 | 12,672 |
| **per block** | **24,992** | **12,704** |
| × 6 blocks | 149,952 | 76,224 |

The saving is `12,320 − 32 = 12,288` per block, i.e. **73,728** in total, not
76,032. The figure 76,032 in the original text is the size of `w2` alone — the
wrong term was picked up while subtracting.

Verified against the constructed model, not on paper:

```
micro-base          29,920,512
micro-branchnorm    29,922,816
micro-staticgate    29,999,040   <- corrected
micro-gated         30,072,768
```

## Why this is the third such slip, and what follows

Amendment 1 to X19 corrected G-2, which claimed the branch norm was free when
`RMSNorm` is affine. The G-2 check in X19's kernel then double-counted the tied
`lm_head` and reported 49,221,504 against an expected 29,922,816. This amendment
corrects a parameter count in a pre-registration.

That is three times in three documents, and the pattern is consistent: **the
parameter arithmetic is written from the design description instead of counted off
the constructed model.** The fix is the same in all three cases and it is not a
sentence in a pre-registration — it is a test that asserts the count. Eight such
tests now exist in `test_branch_norm.py` and `test_export_hf_model.py`, and this
arm's count is asserted by `test_static_gate.py` before any GPU time is spent.

## What is NOT changed

- **H-1's threshold is 4.7544, a loss bar, and is untouched.** No prediction in X20
  depends on a parameter count, so nothing about the experiment's decision is
  affected.
- Arms, seed, step count, data, and the decision rule all stand.
- The direction of the claim is unchanged: the static arm is still a strictly
  smaller module than the gated arm, by 73,728 parameters, and that is still the
  comparison being made.
