# Pre-registration — KALIA-Vision v0: text-to-image on synthetic shapes

Registered: 2026-11-06, before the vision GPU run.

## Goal

Give KALIA a first **image-generation** module, fully from scratch: KALIA
encodes the caption; a small conditional diffusion model draws the requested
shape, color and position. This is a narrow synthetic domain, not
photorealism. It is a real capability module, not a new base model.

## Data

Fully synthetic, generated by our own code:

- 32×32 RGB images, one shape per image.
- Shape: circle, square, triangle.
- Color: red, green, blue, yellow.
- Position: left, center, right.
- Captions: two templates, e.g. “a red circle on the left” and “the square is
  blue and on the right.”
- 50,000 train / 5,000 val / 5,000 test.

No external images. No pretrained vision weights.

## Model

- **Text encoder:** frozen v0.3.1 (58M). Mean-pooled hidden state, 512-dim,
  precomputed once per caption.
- **Image generator:** conditional DDPM, small 32×32 U-Net trained from
  scratch (~5–10M parameters), conditioned on the KALIA text embedding plus
  diffusion timestep.
- **Training:** standard ε-prediction MSE, 1,000-step linear beta schedule,
  batch 128, AdamW. 30-hour window.
- **Sampling:** DDIM, 100 steps.

## Bars

| ID | prediction | threshold |
|---|---|---|
| **W-1** | requested shape appears | ≥ 0.80 |
| **W-2** | requested color appears | ≥ 0.80 |
| **W-3** | requested position appears | ≥ 0.70 |
| **W-4** | from scratch | no pretrained vision weights; KALIA frozen |
| **W-5** | inspectable samples | a held-out caption grid is saved |

Attribute accuracy is measured by a small classifier trained from scratch on
the real synthetic images as a diagnostic. It is not a pretrained model.

## Decision rule

- **W-1…W-3 pass:** release the capability module as **v0.5.0-vision** on
  GitHub. The public base remains v0.3.1.
- **Any fail:** log the null; no image-generation release. Do not tune after
  the result.
- Audio is the next window: a from-scratch speech-command encoder feeding
  KALIA, then TTS.

## Cost

Data generation CPU. Diffusion training ≤ 30 GPU-h; fits the window. The
current 2.87-hour window is used for data and a smoke test, not the full run.
