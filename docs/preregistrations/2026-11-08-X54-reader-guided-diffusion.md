# Pre-registration — X54: reader-guided diffusion consistency

Registered: 2026-11-08, before the X54 GPU run.

## Context

The see→draw→see loop is open. X53 showed the gap is **compositional**:
fine-tuning the captioner on generated *seen* combinations did not transfer to
generated *held-out* combinations, while real held-out captioning stayed at
0.984. The diffusion generates scenes the independent classifier recognizes at
0.948, so the failure is not random generation.

X54 tests the complementary direction: instead of adapting the reader to the
generator, adapt the **generator** so its own samples are readable by the
frozen reader.

## Provenance (from scratch)

Every component is ours:

- text trunk: KALIA v0.3.1, trained from scratch in this repository;
- diffusion U-Net: 3.75M params, trained from scratch on our synthetic data;
- captioner: from-scratch CNN encoder + LoRA decoder, trained from scratch;
- synthetic scenes: generated by `synthetic_vision_v1.py`;
- differentiable sampler and reader loss: written here.

No pretrained vision weights, no external model inference, no distillation
target from another model. The frozen captioner is our own reader; the loss is
a self-consistency objective between two of our own modules, analogous to a
cycle-consistency loss. It is not distillation of an external teacher.

## Treatment

Fine-tune the v1 diffusion U-Net on **seen** combinations only:

- `L = L_diff + λ · L_reader`
- `L_diff`: standard DDPM noise-prediction MSE on real seen images.
- `L_reader`: cross-entropy of the frozen v2.1 captioner on images sampled
  from the current U-Net, conditioned on the same seen captions. The gradient
  flows through a differentiable 20-step DDIM sampler into the U-Net.
- λ = 0.01; 2,500 steps; batch 64 for `L_diff`, batch 8 for `L_reader` every
  2 steps; AdamW lr 1e-4; gradient clip 1.0.
- KALIA, the captioner encoder and the LoRA decoder are frozen.

No held-out combination is used in fine-tuning. Held-out combinations come
from the v2.1 split (29/144, seed 2026).

## Evaluation

1,000 held-out real test images and 1,000 seen real test images.

- **Loop:** real image → captioner c1 → diffusion(c1) → captioner c2; compare
  c1 and c2.
- **Source readback:** source caption → diffusion(source) → captioner c3;
  compare source and c3. This isolates generator-reader agreement from the
  captioner's real-image accuracy.
- **Real caption:** source vs c1 (sanity; captioner frozen).
- **Quality:** from-scratch attribute classifier trained on real train images,
  evaluated on the generated images from source captions.
- **Diagnostic:** baseline loop and readback before fine-tuning, seen vs
  held-out; pixel mean/std of real vs generated.

## Bars

| ID | prediction | threshold |
|---|---|---|
| **R-1** | held-out loop exact (c1 == c2) | ≥ 0.70 |
| **R-2** | held-out loop attribute consistency (each) | ≥ 0.80 |
| **R-3** | held-out source readback exact | ≥ 0.70 |
| **R-4** | generated-image classifier exact, held-out | ≥ 0.80 |
| **R-5** | real caption exact, held-out | ≥ 0.90 |
| **R-6** | from scratch; no external weights/distillation | pass |
| **R-7** | artifacts: checkpoint, metrics, samples, logs | pass |

## Decision rule

- **R-1, R-2, R-3 and R-4 pass:** the reader-guided diffusion closes the loop
  without losing generation quality; release **v0.5.4-vision-cycle**.
- **Any of R-1…R-4 fails:** log the boundary with the seen/held-out split and
  the quality metrics; no tuning after the result. The seeing and drawing
  modules do not share a compositional representation at this scale.
- R-5/R-6/R-7 are integrity checks; a failure there invalidates the run.

## Cost

≤ 2 GPU-h; fits the remaining window.
