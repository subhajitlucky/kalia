# Amendment 1 — X49 runtime: 1,500 steps per arm

Registered: 2026-11-06, before the full X49 GPU run.

## Reason

The 50-step smoke test measured **13.6k tokens/s** on the 58M model. The
registered 2,000-step arm is 524M tokens, which would take **~10.7 hours** —
longer than Kaggle's 9-hour GPU session limit. A split run would change the
re-warm schedule or require a second re-warm, confounding the mixture
comparison.

## Amendment

- Both arms run **1,500 steps** (393M tokens) instead of 2,000, in one session
  each.
- Warmup scales proportionally: **150 steps** instead of 200.
- Everything else is unchanged: v0.3.1 resume, Muon, micro 8 × accum 32 ×
  1024, LR 6e-4, cosine, seed 1501, same control/treatment mixtures.
- Bars **K-1…K-4 are unchanged**. The comparison remains matched.

## Consequences

The continuation is 393M tokens (16.4% of the original 2.4B corpus) instead
of 524M. It is a shorter data-mixture test, not a full second epoch. If it
passes, the seed-1502 replication uses the same 1,500-step schedule.

No result-driven tuning. This amendment is only about fitting the session
limit.
