# Pre-registration — X49: reasoning-heavy continued pretraining at 58M

Registered: 2026-11-06, before the X49 GPU run.

## Context

X47 Stage 0 found the weak spots: OpenBookQA 0.164, ARC-Challenge 0.201,
LAMBADA 0.270, HellaSwag 0.324. The strong tasks are SciQ 0.708, PIQA 0.620,
BoolQ 0.544, WinoGrande 0.523, ARC-Easy 0.480; mean 0.4258.

X48 showed the 32k tokenizer is not a benchmark win at 30M, so GPT-2 BPE stays.
The next lever is data.

## Design

- **Base:** v0.3.1, frozen as the starting point; continued pretraining, not
  from scratch.
- **Arms:** control mixture vs reasoning-heavy mixture, same 524M tokens.
  - Control: 60% FineWeb-Edu / 20% TinyStories / 15% Cosmopedia / 5% code.
  - Treatment: 45% FineWeb-Edu / 5% TinyStories / 40% Cosmopedia / 10% code.
- **Schedule:** the v0.3.0 epoch2 re-warm recipe — Muon, 2,000 update steps,
  micro 8 × grad accum 32 × 1024, LR 6e-4, warmup 200, cosine, 100-batch val.
- **Seed:** 1501 for both arms; only the mixture differs. Replicate with a
  second seed only if Stage 1 passes.
- **Evaluation:** the 9-task suite at 2,000 samples where available; shared
  control validation for bpB.

## Bars

| ID | prediction | threshold |
|---|---|---|
| **K-1** | treatment beats control on the 9-task mean | ≥ +1.0 pp |
| **K-2** | no task regresses | no task beyond 2σ |
| **K-3** | weak-task average improves | ≥ +1.5 pp on OpenBookQA/ARC-C/LAMBADA/HellaSwag |
| **K-4** | language quality | treatment val bpB ≤ control + 0.01 |

K-1 and K-3 are the primary bars. A positive Stage 1 triggers a second seed;
a null parks this mixture.

## Decision rule

- **K-1, K-2, K-3 pass:** replicate seed 1502 in the next window; if both
  seeds pass, the 58M base with the winning mixture is the next release
  candidate.
- **K-1 or K-3 fails:** park the mixture; do not tune ratios after the result.
  A different mixture is a new registration.
- **K-4 fails:** the treatment costs language quality; report and do not
  release even if a benchmark task moves.

## Cost

Two 58M arms × 2,000 steps ≈ 24 GPU-h; fits the 30-hour window, with
resumable sessions if a single session hits the 9-hour limit. Data prep is
CPU-only.
