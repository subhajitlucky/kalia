# Pre-registration — X53: cycle-consistency fine-tune

Registered: 2026-11-08, before the cycle-fix GPU run.

## Context

The see→draw→see cycle failed: cycle exact **0.032**, attribute consistency
0.278–0.476. The v1 classifier recognizes generated images at 0.948, so the
gap is the captioner's real-image distribution, not random generation.

## Treatment

1. Generate **10,000 images** from the v1 diffusion using captions of **seen**
   combinations (no held-out combinations).
2. Fine-tune the v2.1 captioner on **generated images + source captions**
   (10k) plus **real-image replay** (10k), 2 epochs.
3. Re-test:
   - cycle on 1,000 held-out real images,
   - real caption exact on the same held-out images.

No pretrained vision; KALIA frozen; diffusion frozen.

## Decision rule

- **X-1/X-2 pass with X-3:** release **v0.5.4-vision-cycle**.
- **Fail:** log the boundary; no tuning after the result. The gap is real at
  this scale.
- This is a cross-modal discovery test, not a benchmark chase.
