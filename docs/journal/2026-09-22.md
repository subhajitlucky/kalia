# Journal — 2026-09-22 (Build Day)

## Decisions

- **Platform: Kaggle** over Colab/Lightning. Evidence: documented 30 GPU-h/week,
  T4×2 32GB, background commit runs, 20GB persistent storage, no card.
- **From-scratch training**, not fine-tuning: weights must be exclusively ours.
- **Size: ~58M params** (10 layers, 512 dim, 8 heads, ctx 1024, GPT-2 BPE).
- **Data: TinyStories (~474M tokens) + FineWeb-Edu (2.0B)** → train.bin 2.46B
  tokens, val.bin 10M tokens.
- **Multi-session training harness**: checkpoint to HF Hub every 30 min, resume
  by step counter. Built for free-tier survival.
- **Incremental ladder v0.1.x**: one change per version, micro-ablation first,
  full run only for winners (see `docs/plans/2026-09-22-kalia-v0.1-ladder.md`).

## Build results

- 13 implementation tasks, TDD throughout: model, data, tokenizer, trainer,
  sampler, notebooks, docs. 20 tests at first green build.
- Data prep ran on Kaggle CPU in ~37 min: TinyStories 473,992,236 tokens;
  FineWeb-Edu 2,000,001,223 tokens; train 2,463,993,459 + val 10,000,000.

## Incidents (all resolved)

| # | Incident | Root cause | Fix |
|---|---|---|---|
| I1 | API-pushed Kaggle runs cannot read secrets (`HTTP 400` on `get_secret`) | Secrets attach per-notebook via UI only; API-kernel versions do not carry them | Start real runs from the browser; added fail-fast HF connection test cell |
| I2 | `FileNotFoundError: configs/kalia-m.yaml` in first GPU run | `kaggle datasets create` default `--dir-mode skip` drops subdirectories | Config flattened into dataset root; notebook asserts it exists |
| I3 | `torch.OutOfMemoryError` at step 1 | batch 32 × ctx 1024 → fp32 logits cast > 13GB on a 14.5GB T4 | `micro_batch 8 × grad_accum 32` (same effective batch) + `PYTORCH_ALLOC_CONF=expandable_segments:True` |
| I4 | Failed `!torchrun` still marked the version COMPLETE | `!` command failures do not fail a notebook cell | Replaced with `subprocess.run` + `assert returncode == 0` |
| I5 | Personal details in docs / commit author | Written early, before privacy request | Docs scrubbed; git history rewritten with a neutral author, then again to the owner's identity on request |
