# Journal — 2026-10-17 (external audit, exposure check, second-seed replicas launched)

The day the project was audited from the outside — published artifacts, secrets,
and its own record — and the first time a replication was launched through a
stager that cannot silently run the wrong arm.

## External audit of the published artifacts

A full read-only audit of everything published on HF and Kaggle, with
calibrated anonymous probes (a known-public control must answer before any
private/public verdict is read).

  the continual-update programme (journal 2026-10-08) — **while the model card

  verified structurally: 93 float32 tensors, tied head kept, checkpoint

  ≈59 GB of permanent LFS history, because every 30-minute checkpoint push is a

## Findings from the strategic review (recorded, not yet decided)

Reading the whole record back surfaced items the numbers already support:

1. **QK-Norm + soft-cap has never cleared our own noise floor.** The micro
   increment is −0.083 nats (3.5937 → 3.5103), single-seed, bundled
   (QK-Norm and soft-cap never isolated), against a measured 30M control spread
   of ≈0.11. Under D48's standard it is the one shipped recipe ingredient whose
   evidence sits below the ruler — and it is advertised on both cards. A
   2-seed ablated re-test is ~2–3 GPU-h.
2. **The benchmark sample size is a self-inflicted noise floor.** D45 is the
   project's power thesis, and the benchmarks run on CPU (quota-free), yet
   `--limit` is still 500 (σ≈2 pp). 2,000 samples halves σ for zero GPU cost,
   and no accuracy claim in the next release should ship before it.
3. **The WSD / flexible-decay recommendation from the 2026-09-23
   reprioritization never landed.** v0.2.0 then paid 6.3 h for a flat final 31%
   that WSD's target-margin decay exists to avoid.
4. **The bundle-drift class (I10, I23, X29-v1) should be engineered away, not
   caught.** Kernels mount a stale `kalia-code-dev` snapshot; cloning the
   public GitHub repo at a pinned commit (no secret needed) removes the class,
   and the run record should carry the code revision + dataset versions.
5. **HF checkpoint history ≈59 GB** for a 58M model pair. Training sync belongs
   in a repo that stays private; release repos carry the final artifact.
