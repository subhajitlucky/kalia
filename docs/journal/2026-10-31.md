## What is being tested

The mechanism is the **Counterfactual Residual Bottleneck**: each block's
residual delta is split by a shared orthonormal rank-64 projection into a
stable stream and a volatile complement. The sum is the standard residual, so
the language path is invariant to the split by construction; the LM loss has
exactly zero gradient on the projection. The paired counterfactual loss trains
the stable stream to ignore consistent renames/synonyms and react to role
swaps, negation, number and spatial changes.

The bars, fixed before the run in `2026-10-28-X38-crb-micro.md`:

- **C-1** CRB val ≤ split + 0.005 (no language tax).
- **C-1b** split val ≤ control + 0.005 (the decomposition is a
  reparameterisation).
- **C-2** CRB swap sensitivity ≥ split + max(split seed spread, 0.01), both
  seeds.
- **C-3** CRB held-out paraphrase distance ≤ split − 0.01, both seeds.
- **C-4** CRB greedy retention ≥ split − 0.005 (secondary).
- **C-5** stable stream effective rank > 8, norm > 0.01, and the projection
  changed from init by > 1e-3, both seeds.
- **C-6** pair audit clean.

A win requires **C-1, C-2, C-3 and C-5**. If it passes, the 58M control-vs-CRB
confirmation is next. If C-1 fails, no scale.
